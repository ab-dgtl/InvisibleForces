# Проект «Невидимые опоры»

Одностраничный статический сайт для заказа услуг нумерологического анализа и раскладов Таро.
Весь текстовый контент взят **дословно** из файла `Проект Невидимые опоры.docx` — ничего не добавлялось и не переписывалось. Собственные слова автора сайта ограничены только интерфейсными элементами (подписи кнопок, названия полей формы, дата в подвале).

## Цветовая гамма и стиль

- Тёмно-фиолетовая палитра (`#10062a` → `#3d2183`) + золото (`#f6ecc9` → `#a8841b`).
- Шрифты: Cormorant Garamond (заголовки), Jost (текст) — Google Fonts.
- Иконки: Font Awesome 6 (CDN jsDelivr).
- Тонкие детали: звёздное поле на canvas, медленно вращающаяся мандала за заголовком, золотые орнаменты-разделители со звездой, мягкое свечение фона, плавное появление блоков.

## Реализованные функции

1. **Hero** — название проекта, описание, плашка «Нужна только ваша дата рождения!», кнопка заказа.
2. **Зачем нужен нумерологический анализ** — 5 карточек + блок «скрытые аспекты и взаимосвязи».
3. **Тарифы** — Silver 3 500 р и Gold 15 000 р (флагманская карточка), кнопки выбора тарифа.
4. **Отзывы** — секция-заготовка (три карточки с цитатами); наполняется позже.
5. **Обо мне** — 4 абзаца + фото г. Кайлас (Тибет).
6. **Таро** — «12 сфер жизни» и «12 карт 12 месяцев», по 7500 руб, фото свечи.
7. **Темы** — 3 пункта с иконками.
8. **Форма заявки** — имя, дата рождения, телефон, почта, тариф; валидация на клиенте, запись заявки через RESTful Table API.
9. Адаптивная вёрстка (desktop / tablet / mobile), поддержка `prefers-reduced-motion`.

## Целевая точка конверсии

Форма в секции `#order`. Пользователь заполняет: **имя, дата рождения, телефон, почта** (+ тариф) и отправляет заявку.

## Точки входа (URI)

| Путь | Назначение | Параметры |
|------|-----------|-----------|
| `/index.html` | Главная страница (все секции) | — |
| `#hero` | Первый экран | — |
| `#about-analysis` | Зачем нужен анализ | — |
| `#tariffs` | Тарифы Silver / Gold | — |
| `#reviews` | Отзывы | — |
| `#about-me` | Обо мне | — |
| `#tarot` | Расклады Таро | — |
| `#topics` | Дополнительные темы | — |
| `#order` | Форма заявки | — |
| `tables/orders` | RESTful Table API | `POST` — создать заявку; `GET` — список |

## Данные

Таблица `orders` (хранение заявок):

- `id` (text) — идентификатор заявки;
- `name` (text) — имя;
- `birth_date` (text) — дата рождения;
- `phone` (text) — телефон;
- `email` (text) — почта;
- `tariff` (text) — выбранный тариф/услуга;
- `created_at` (datetime) — дата заявки.

Запись выполняется из `js/main.js` методом `POST tables/orders`.

## Публичные URL

- Продакшн: публикуется через **Publish tab / Hosted Deploy** (URL выдаётся платформой).
- API заявок: относительный путь `tables/orders` от корня сайта.

## Не реализовано / возможные доработки

1. **Отзывы** — реальные тексты и фото (блок подготовлен, нужно только наполнить).
2. **Уведомления** — сейчас заявка сохраняется в таблицу; интеграция с e-mail/Telegram/WhatsApp требует внешнего сервиса (webhook), что выходит за рамки статического сайта.
3. **Маска телефона** — сейчас мягкая валидация; можно подключить библиотеку маски.
4. **Политика конфиденциальности** — для сбора персональных данных рекомендуется добавить страницу и согласие на обработку.
5. **SEO/OG-разметка** — добавить Open Graph и микроразметку услуг.
6. **Капча/антиспам** — простейшая honeypot-защита формы.
